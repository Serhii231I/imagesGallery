# 🖼️ Images Gallery

A responsive image search and gallery application built with **React and TypeScript**.

The application allows users to search for images, browse search results, and open images in a larger modal preview.

## 🏗️ Application Structure

The application is built using reusable React components and separates UI components from API-related logic.

Main application parts include:

- Search form
- Image gallery
- Image cards
- Image modal
- Loading indicator
- Error/notification handling
- API service

## 🌐 API Integration

The application communicates with an external REST API to retrieve image search results.

**Axios** is used to perform asynchronous HTTP requests and handle communication with the API.

The application processes:

- Search queries
- Image results
- Image URLs
- Image metadata
- Pagination data

## 🔍 Image Search

Users can enter a search query to find images.

After submitting the search form, the application sends an asynchronous request to the API and displays the returned images in a responsive gallery.

## 🖼️ Image Preview

Users can click on an image to open a larger version in a modal window.

The modal functionality is implemented using **React Modal**.

## ⏳ Loading & Error Handling

The application provides visual feedback while API requests are being processed.

**React Loader Spinner** is used to display loading indicators.

**React Hot Toast** provides notifications for important user actions and API-related errors.
